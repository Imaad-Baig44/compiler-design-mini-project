# Compiler Design Mini Project

## 📌 Project Title
Lexical and Syntax Analyzer for a Hypothetical Language

---

## 📖 Description
This project implements the first two phases of a compiler:
- Lexical Analysis
- Syntax Analysis (LL(1) Parsing)

The system reads a source program, converts it into tokens, and checks whether the program follows correct syntax using grammar rules.

---

## ⚙️ Technologies Used
- Python
- Regular Expressions (re)

---

## 🔹 Lexical Analysis
- Identifies tokens like:
  - Keywords (int, main, begin, do, while, return, end)
  - Identifiers (n, expr, exp)
  - Operators (=, +)
  - Symbols ((), ;)

---

## 🔹 Syntax Analysis
- Uses LL(1) parsing technique
- Implements:
  - Stack-based parsing
  - Grammar rules
  - Step-by-step parsing actions
